# Suggested CV entry

**FairSkin-AI — Fairness-Aware Dermatology Image Classification**  
Python, PyTorch, torchvision, scikit-learn, Streamlit

- Built an end-to-end deep-learning pipeline for three-way dermatology image classification using transfer learning and reproducible train/validation/test splits.
- Audited performance across Fitzpatrick skin-tone subgroups using subgroup accuracy, balanced accuracy, macro F1/recall, bootstrap confidence intervals, and maximum performance gaps.
- Implemented bias-mitigation baselines including class-weighted loss and intersectional class-by-skin-group sampling for controlled before/after fairness experiments.
- Developed a Streamlit research dashboard for model predictions, confidence visualization, and subgroup-level fairness context, with a strict non-clinical-use disclaimer.
